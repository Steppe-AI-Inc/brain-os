# v0.6 Development Plan

## Goal

Make SEM Brain ready for real AI execution without burning tokens or exposing API keys.

## Acceptance criteria

1. App loads locally with no backend.
2. Fallback mode creates tasks with zero token usage.
3. Real AI mode calls a secure backend endpoint only.
4. Context pack sends minimal relevant data, not full workspace.
5. Token preflight estimates command cost before AI execution.
6. High-risk tasks create approvals.
7. Employee view hides ownership/cash/salary unless authorized.
8. Patch-only Module Registry prevents full-system rewrites.

## Next after v0.6

v0.7 should add:

- Real Supabase normalized tables instead of localStorage JSON
- Supabase Auth user invitations
- Row Level Security policies
- Gmail / Calendar / Telegram connectors
- AI-generated daily brief scheduler
- GitHub integration for software factory
