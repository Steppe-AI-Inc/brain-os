Before production pilot, the CEO needs a visual operating brain and a QA/QC gate.
This version adds:

1. Real-data 2D operating mindmap.
2. QA/QC Lab with non-destructive tests.
3. Architecture Audit page for token-safe development and multi-agent readiness.

## Token safety

The mindmap uses local database state only. It does not call the AI backend.
QA tests are also local/dry-run and do not call OpenAI/Claude.
