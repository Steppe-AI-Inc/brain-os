# Factory auto-enrollment — transport compatibility matrix (non-regression contract)

Binding requirement (founder, 2026-09-26, corrections §4 / governance §5, §6, §10): the permanent architecture changes the
TRANSPORT (`NODE → runner.env → raw PostgreSQL`) into `NODE → node-scoped credential → Factory Node API → SAME canonical
control-plane state machine`. The API wraps the SAME canonical lifecycle semantics. It creates no second orchestration engine,
in Edge Functions or anywhere else.

**Semantic reference:** frozen certified baseline `69df2f52f71fd2bc9415c34fb2be4dab4ee08dd6` (`scripts/factory-runner/claim.mjs`,
`node.mjs`, `handlers/factory-acceptance.mjs`). Line numbers below are at that SHA.

**Rules of this file.**
- It is committed BEFORE any claim / renew / checkpoint / complete transport change.
- A row's VERDICT becomes `MIGRATED` only when the old invariant has **executable regression coverage passing on the new server
  primitive**. Until then it is `PENDING`. `qa/factory/transport_compatibility_contract.mjs` enforces this against the evidence
  files.
- **A new primitive may tighten atomicity of the SAME rule** (e.g. a read-then-write fence becomes one transaction). It may never
  change which outcome the rule produces. Every such tightening is marked **[atomicity only]**.

**One-engine design.** Every NEW SERVER PRIMITIVE below is a function `factory._op_<name>(ctx, args)` in
`supabase/control-plane/006_lifecycle_core.sql`. Its body is the old statement(s) moved server-side verbatim, except that
authority comes from `ctx` (re-derived server-side) instead of a caller parameter. It is reachable only through:
- `factory_api.node_call(session, op, request_id, args)` — the Node API, node-scoped credential. `ctx` comes from session →
  active credential → active computer → tenant → CURRENT envelope.
- `factory_legacy.node_call(node_id, op, request_id, args)` — the branch's direct-PG transport, used by the certified suites.
  `node_id` is self-asserted: the documented legacy residual, closed by retiring `factory_runner`.

**Mixed fleet.** Frozen-code legacy nodes keep issuing their inline SQL against the same tables until they re-enroll. The core
therefore keeps the baseline's plane-wide claim serialization **`pg_advisory_xact_lock(hashtext('factory.claim'))` unchanged**.
A tenant-scoped key would stop serializing against legacy claimers, and the heavy-limit counts would race (measured L8,
2026-09-22). `qa/factory/legacy_compat_acceptance.mjs` runs the 69df2f52 runtime against a migrated plane.
