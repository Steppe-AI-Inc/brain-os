## Classification rules

- **LIVE ONLY** - present in the verified live catalog but absent from repository schema.
- **REPOSITORY ONLY** - present in migrations/bootstrap schema but absent from verified live.
- **MATCH** - live and repository definitions agree.
- **CONFLICT** - the object exists in both with materially different definitions, or two
  repository sources make incompatible claims about live state.
- **DEPRECATED/UNCERTAIN** - historical, generated by an unverified process, or impossible
  to classify without live evidence.

Until live access is restored, this report uses **DEPRECATED/UNCERTAIN** rather than
guessing that an object is a match.

## Live catalog inspection checklist

A fresh personal access token and database credential are required. Run these commands
from a trusted workstation; never paste either credential into git:

```powershell
npx --yes supabase@latest login
npx --yes supabase@latest link --project-ref pvphxgrtdfrudejjhzjk

# Read-only schema capture. Store output outside git while reviewing.
npx --yes supabase@latest db dump --linked --schema public --file .phase0/live-public.sql

cd web
$env:SUPABASE_PROJECT_REF = "pvphxgrtdfrudejjhzjk"
npm run db:types
```

The read-only catalog review must compare:

1. `pg_class`, `pg_namespace`, and `information_schema.columns` for tables,
   views, columns, types, defaults, identity/generated attributes, and RLS flags.
2. `pg_constraint` for primary, foreign, unique, and check constraints.
3. `pg_indexes` for explicit and implicit indexes.
4. `pg_proc` for signatures, owners, volatility, security-definer mode, and configured
   `search_path`.
5. `pg_trigger` for non-internal triggers.
6. `pg_policies` for every command, role, `USING`, and `WITH CHECK` expression.
7. `pg_extension` for installed versions and schemas.
8. View options and grants, especially `security_invoker`.

After capture, replace every provisional classification in this report with
**LIVE ONLY**, **REPOSITORY ONLY**, **MATCH**, **CONFLICT**, or a justified
**DEPRECATED/UNCERTAIN** entry at object/column level.
