# SEM Brain v0.7 Production Core

This version moves SEM Brain from prototype UI toward real production architecture.

## What changed

- Added **Production Core** page.
- Added browser-side Supabase configuration tester.
- Added Supabase v0.7 schema with real tables and RLS policies.
- Added sensitive-table separation for ownership/cash/salary.
- Added Supabase Edge Function that builds compact context from DB with RLS.
- Added work order, model usage and audit log write path.
- Fixed script loading so all modules are loaded.
- Added data service for testing real Supabase login and table access.

## Honest status

This is still a local/static UI package unless deployed.

It becomes real multi-user software only after:

1. Create Supabase project.
2. Run `supabase/schema-v0.7-production-core.sql`.
3. Create users in Supabase Auth.
4. Create matching rows in `profiles` and `company_memberships`.
5. Deploy the Supabase Edge Function.
6. Add backend secrets.
7. Configure the app in **Production Core**.
8. Test Founder and Employee access.

## What is real now

- Database schema is real.
- RLS policies are real.
- Edge function code is real.
- Token/context design is real.
- Audit/work order/model usage tables are real.
- Local UI still works without cloud.

## What is not fully real until deployment

- Employee login sessions.
- Server-enforced permissions.
- Real AI execution.
- Slack/Google Drive OAuth.
- File upload to Supabase Storage.

## Production acceptance test

1. Founder logs in.
2. Founder runs AI Native Chat command.
3. Backend writes a work order.
4. Backend creates tasks and approvals.
5. Backend logs model usage.
6. Backend writes audit log.
7. Employee logs in.
8. Employee sees own tasks only.
9. Employee cannot query `company_sensitive`.
10. Employee cannot query another person salary.
