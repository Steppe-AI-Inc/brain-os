# SEM Brain v0.6.4 AI Native ChatOps Patch

## Goal
Make SEM Brain AI-first: the founder should operate the company from one chat command. Menus remain dashboards/checking tools, not the primary workflow.

## Added
- AI Native Chat page
- ChatOps orchestrator
- Workflow Factory
- Autonomous QA page
- AutoTest runner
- AI work order log
- Workflow run log
- Chat-first command shortcuts

## Architecture
The system now follows:

Founder chat command
→ minimal context pack
→ token preflight estimate
→ command classification
→ scoped AI manager assignment
→ workflow execution
→ approval gates
→ QA/evidence check
→ memory/task/work-order logs

## Token-safe development rule
Do not recreate the full system for one change. Use Module Registry and patch-only prompts.

Allowed patch style:
- modify one module
- update one prompt
- add one test
- no full-app rewrite

## Real AI Status
v0.6.4 is still safe fallback/local mode unless Real AI Backend is enabled. It is designed for API-backed AI later but consumes zero AI API tokens by default.
