# SEM Brain v0.6.2 Ops Automation Patch

Patch-only update. No full rebuild.

## Added modules

- `js/modules/documents.js` — upload documents, paste current knowledge, create source-linked memory snippets.
- `js/modules/productInventory.js` — product lines, pricing, SKU/inventory, low-stock approval tasks.
- `js/modules/dealDesk.js` — live meeting notes to quotation, proposal draft, approvals, Slack/Drive queues.
- `js/modules/integrations.js` — Slack and Google Drive connector readiness, settings, outbound queues.
- `js/modules/automationExplorer.js` — automation backlog and one-click automation design tasks.

## Updated modules

- `js/main.js` — navigation routes for new modules.
- `js/core/store.js` — seed data and schema structures for docs, products, inventory, quotations, integrations and automation ideas.
- `js/ai/contextPack.js` — adds relevant docs/product/inventory/quotation slices without sending full workspace.
- `js/ai/pipeline.js` — new command categories: deal_desk, knowledge, inventory, integrations.
- `js/modules/mindmap.js` — adds docs, products, inventory and quotations into operating mindmap.
- `js/modules/qaLab.js` — tests new module presence and data structures.
- `js/modules/moduleRegistry.js` — patch-only prompts for new modules.

## Token policy

- Document upload creates small snippets instead of pushing full files to AI.
- Deal Desk uses product catalog and selected quote lines; it does not send full workspace.
- Slack and Drive actions are queued and approval-gated.
- Integration execution should happen through backend functions only.

## Production notes

Static MVP simulates integrations. Real Slack/Google Drive requires OAuth and server-side tokens.
