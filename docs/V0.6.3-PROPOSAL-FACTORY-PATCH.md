# v0.6.3 Proposal + Quotation Factory Patch

## Objective

Make SEM Brain useful during client meetings by generating quotation/proposal packages immediately from product lines, inventory, templates, and payment terms.

## New user workflow

Meeting notes / client request
→ select product bundle
→ select payment terms
→ generate quotation + proposal
→ run approval rules
→ export client HTML
→ export internal margin report
→ queue Slack approval
→ queue Google Drive archive
→ create version history
→ block risky deals until approved

## Approval rules

- Discount <= 5%: standard internal approval
- Discount 5–15%: manager approval
- Discount > 15%: founder approval
- Negative margin: blocked until repriced
- Barter/fuel/financing: founder/finance approval
- Inventory shortage: procurement or manufacturing approval task

## Token efficiency

The module is deterministic and local. It does not call an LLM to generate every proposal. Future AI refinement should use a compact context pack containing only:

- selected quote template
- selected proposal template
- selected payment terms
- selected product lines
- selected client/lead
- relevant source memories/documents
